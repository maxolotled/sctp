Firefly World Map Project

Mapping the whole 50k×50k world :D!

How to participate

  1. Claim one or multiple maps on this website
  2. Take a free max-sized map from /pw map
  3. Make the fully filled-out map of the location you picked
  4. Rename it and submit it to the hoppers at /pw map
  5. Mark the area as completed on the website

Each map you complete pays out 3 diamonds, paid once the whole project is finished.

Changes you make below (claiming/finishing maps) can take a minute or two to show up for other people.
