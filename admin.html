Verification links
Generate a single-use, expiring link tied to a Minecraft username. Whoever opens it can create a brand-new account or link an existing one — either way that Minecraft username becomes verified. Send it to the player privately.
Mapart takedown requests
Owners can ask for a mapart they claimed to be removed from SCTP for good. Approving deletes it and blocks it from coming back (its map ids and its exact picture). Denying leaves it up. The requester is notified either way.
