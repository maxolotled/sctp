Trading Post Marketplace Docs

Features

Everything Shop Logger and the Trading Post website can do, and how to use each one.

Manual & automatic scanning

Right-click a shop chest or barrel to log it instantly. Or toggle auto-scan (Controls → Shop Logger, unbound by default) to have the mod silently scan known shops as you walk within ~4 blocks.

Automatic world detection

Automatic — on join, or when you switch worlds via a server reconfigure, the mod figures out whether you're on Firefly or Honeybee on its own. /setworld firefly / /setworld honeybee is only needed as a manual fallback.

Shared Trading Post upload

Uploads your scan log automatically every 15 minutes, or press the Upload keybind (Controls → Shop Logger) to send immediately.

In-game /search

Type /search <item> in chat. Opens a browsable results screen by default, or plain chat output if you'd rather (switchable in Settings).

Teleport beam

Click the TP button on any listing row (search results, an item page, or a seller profile). Sends /shop <seller> and draws a particle beam from you straight to the chest that moves with you as you walk — press X to cancel it early.

Shop visit alerts

Automatic — the first time you scan any chest at a shop each hour, the mod checks what's appeared there since your last visit and tells you in chat, rares first. Restrict it to rares-only in Settings.

Searchable website

Filter by world, currency, price, stock, listing type, and more on the Trading Post homepage — see when each listing first appeared with the "Available since" column.

In-game item library

Press X (default) to open a home screen with the vanilla & rare item libraries, item pages with price history, and seller profiles — the website's data, without tabbing out.

Website item library

Browse every vanilla and rare item at /items/ on the website, with icons, filters, and price history.

[DISPLAY] signs

Use [DISPLAY] as a sign's first line instead of [PRICE] to showcase a build without it being logged as a real sale.

Bulk detection

Automatic — a shulker box in a shop chest that's entirely one item type is logged as a bulk listing. Selling both a bulk batch and a normal stack of the same item shows as two separate listings, not one overwriting the other.

Bundle detection

Automatic — same idea as bulk shulkers: a bundle that's entirely one item type is logged as "bundled," so it's not mistaken for a single sale.

Enchanted book naming

Automatic — enchanted books are logged by their actual enchantment (e.g. "Sharpness V") instead of the generic "Enchanted Book".

Chat scan log

Optional toggle (Controls → Shop Logger, or Settings) that prints everything found in a scan to chat — choose one consolidated line or the full per-item breakdown.

Recently-scanned markers

Optional toggle — shows a subtle particle over the sign of chests you've scanned recently, so you can see what's already logged. How long "recently" lasts is configurable in Settings.

Automatic cleanup

Automatic — sold-out items, emptied chests, and shops that no longer exist are removed from the website the next time that spot gets scanned.

Item cooldown countdowns

Automatic — hover over a rotating quest scroll or a rare item with a use cooldown to see a live countdown right in the tooltip.

Butterfly Garden helper

Automatic — just visit the Butterfly Garden. A resizable, collapsible HUD shows your butterfly counts, and highlights which items in the exchange screen are actually yours to sell.

Keybindings & Settings

Everything above can be bound under Controls → Shop Logger, or tuned from the in-game Settings screen (X → Settings) — cooldowns, chat format, search mode, and the rares-only alert toggle all live there.

How to download & install the mod

Shop Logger is a client-side Fabric mod, and it only needs to be installed on your own computer, not the server.

1. Install Fabric Loader

Download and run the installer from fabricmc.net, be sure to choose the same Minecraft version you play. Pick "Client" and hit Install. This is not needed if you already have Fabric installed. The minimum version is 0.19.3!

2. Get Fabric API

Shop Logger needs Fabric API installed alongside it - it's not optional! Download the version matching your Minecraft version.

3. Download Shop Logger

Grab the jar for your Minecraft version from the Trading Post homepage ("Download mod") - there are separate versions for 1.21.11, 26.1, and 26.2, so be sure to pick the right one!

4. Drop both jars into your mods folder

Open your Minecraft folder (%appdata%\.minecraft on Windows) → mods. Put the Fabric API jar and the Shop Logger jar in there together.

5. Launch with the Fabric profile

In your launcher, select the "Fabric Loader" profile the installer created, and press Play. Shop Logger loads automatically!

Note: The above steps are for the official Minecraft launcher. If you use a third-party launcher, the steps may differ slightly, but the general idea is the same: make sure to use Fabric, then put both jars in your mods folder.
