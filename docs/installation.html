Installing Fabric ​

Important:

This tutorial assumes you are using the default MC launcher. If you use Modrinth, Prism, Lunar, Feather, or a similar modded launcher, a different method may apply. I recommend you to use Google if that is the case.

Downloading & running the installer ​

Start by downloading and running the official Fabric installer. You will see a screen like this:

I: Please select the Minecraft version. For the SCTP mod, select 26.2.

II: Please select the most recent loader version available, usually selected by default.

III: Please make sure the Launcher Location is correct. Usually, the default will be correct.

IV: Make sure 'Create profile' is checked, and press 'Install'.

Launching Minecraft ​

Run the new profile created by the launcher first, so it can make the mods folder. Make sure the correct profile is selected (fabric-loader-XXX) and press play.

Downloading the Fabric API ​

Next up, we will download the Fabric API - it's a mod that is required for the SCTP mod to function. Start by going to the page on curseforge.

I: Select the same game version you picked during the installation process, in this case 26.2.

II: Press download, and put the file in a place you will remember for later.

Downloading the SCTP mod ​

Next, we will download the SCTP mod, called shoplogger. You can download it by going to the sctp homepage and pressing the Download button.

I: Select the correct game version (26.2) and put it in a place to remember for later.

Safety

If you want to confirm the source code yourself before downloading, you can check out the github repository.

Installing the mod files ​

For the last step, we need to put the mod files into the directory of the Fabric installation we made. Start by navigating to where you put the two downloaded mod files.

I: Copy the mod files: one for fabric API and one for SCTP.

II: Navigate to the mod directory by pasting %appdata%\.minecraft\mods in your navigator bar (marked with the arrow), or open the folder via your launcher

III: Paste the files into this mods folder.

Done ​

Congratulations, you have successfully installed the SCTP mod into your Minecraft, and can now start using it! Thank you for helping maintain the website. Check out the features now!
