Need help registering your SCTP account? ​

Please select the correct options to find the solution to your problem.

What issue are you having? ​

I forgot my password

Please DM @ectf on Discord to request a password reset. Please include your Minecraft username and the platform you play on (java/bedrock).

I'm struggling to join the server

What platform do you play on? ​

Java edition

Make sure you copy and paste the IP exactly as provided by the website. If Minecraft warns you about an incompatible version, join anyways. Still not working? Please DM @ectf on Discord to request a manual account creation.

Bedrock edition

Make sure you copy and paste the IP and port exactly as provided by the website, then add the server to the list. Ignore any warnings about incompatible versions or locations, and join anyways. Still not working? Please DM @ectf on Discord to request a manual account creation.

I get told I already have an account

DM @ectf on Discord to delete your previous account or reset your password! Please include your Minecraft username and the platform you play on (java/bedrock).

My username is incorrect

What platform do you play on? ​

Java edition

Your account will automatically be named after the person who joined the unique server IP you received. Make sure to use the correct account to join.

Bedrock edition

Make sure you entered your username without the . in front! If you did that correctly, and the verification process still is not working, please DM @ectf on Discord.
